## 🏛️ Müfredat Mimarisi (Curriculum Blueprint)

Her bir ders aşağıdaki katı pedagojik ve mimari şablona göre hazırlanmıştır:
* ⚡ **Mimari Akış ve Süreç Şeması (ASCII):** Veri akışı, bileşen etkileşimleri ve sistem sınırları.
* 💡 **Aptala Anlatım (ELI5 Metaforu):** Gerçek hayattan eğlenceli ve akılda kalıcı benzetmeler (Türkçe & İngilizce).
* 🔍 **MAANG Seviyesi Teknik Derinlik:** Staff+ seviyesinde trade-off analizleri, P99 gecikme süreleri ve ölçekleme prensipleri.
* ☕ **Modern Java 25 LTS & Spring Boot Kodu:** Virtual Threads (Project Loom), Records, Pattern Matching ve kurumsal servisler.
* ⚠️ **Mülakat Tuzağı ve Anti-Pattern:** Mülakatçıların adayı elemek için kurduğu tuzaklar ve kaskat arıza riskleri.
* 🎯 **Mülakatta Hatırlanacak Altın Kurallar:** 3 adet vurucu mimari ilke (Türkçe & İngilizce).

## 🌐 Web Companion Reader (İnteraktif Web Okuyucu)

500 ders arasında gezinmek, anlık arama yapmak ve çift dilli okumak için modern Single Page Application:
* **Canlı Arama:** 500 ders arasında gerçek zamanlı filtreleme (Örn: *Kafka, Kubernetes, Saga, ZGC, DDD*).
* **Dil Seçici:** 🌐 İkisi (Yan Yana Çift Dilli), 🇹🇷 Sadece Türkçe, 🇬🇧 Only English.
* **PDF İndirme Kütüphanesi:** 551 PDF dosyasını tek tıkla açma ve indirme.
* **Kopyalama Araçları:** ASCII şemalarını ve Java 25 kod bloklarını tek tuşla panoya kopyalama.

Yerel olarak çalıştırmak için:
```bash
python3 -m http.server 4599
# Tarayıcıda açın: http://localhost:4599/web/index.html
```

## ☕ Çalıştırılabilir Java 25 & Spring Boot Örnekleri

Kitaptaki mimari ilkeleri doğrudan test etmek için `examples/` klasöründe 4 adet çalıştırılabilir Java 25 referans kodu hazırlanmıştır:

1. **`OrderProcessingUseCase.java`:** Clean Architecture Interactor, Hexagonal Ports & Adapters, Java 25 Records.
2. **`DynamicStrategyEngine.java`:** Spring DI uyumlu Dinamik Strateji Kalıbı ve OCP ilkesi.
3. **`CircuitBreakerDemo.java`:** Resilience4j durum makinesi (Closed, Open, Half-Open) ve Graceful Fallback.
4. **`LoomVirtualThreadBenchmark.java`:** 10.000 eşzamanlı işlemi 400 ms'de işleyen Java 25 Virtual Threads testi.

Tüm örnekleri çalıştırmak için:
```bash
java examples/src/main/java/com/maang/se/cleanarch/OrderProcessingUseCase.java
java examples/src/main/java/com/maang/se/patterns/DynamicStrategyEngine.java
java examples/src/main/java/com/maang/se/resilience/CircuitBreakerDemo.java
java examples/src/main/java/com/maang/se/concurrency/LoomVirtualThreadBenchmark.java
```
